## Component-Level Analysis

In this section, you can focus on a single component to analyze its contributions and sensitivities. Select any component and explore its process-level impacts, and parameter sensitivities across scenarios and region.

### Charts:
- Three ranked bar charts showing the most relevant process contributions for the selected component, broken down by scenario and country variation  
- Ranked bar chart of the most relevant impact categories for that component  
- Component-level sunbursts comparing uncertainty across countries and scenarios  
- Tornado plot showing a component’s sensitivity when individual scenario parameters are changed  


### Global component selector
- Select a specific component with the global selector (shown below) to set all of the remaining tabs to show results for the selected component. Within each of the tabs it is still possible to select another component using the local override selector.
