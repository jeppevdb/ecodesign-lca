## Design Change Comparison

Compare the baseline design against one or more alternatives. This tab helps you visualize the impact of each proposed change.

### Graph Descriptions

- **Process contribution comparison - bar chart**  
  Side-by-side bars of total impacts for the baseline and each design variant, broken down into stacked elements representing process contributions.
- **Comparison across life cycles - bar chart**  
  Bar chart showing the impact across life cycles for the baseline and each design variant.
- **Effects per impact category - radar chart**  
  Multi-axis plot comparing baseline and variants across multiple impact categories.  
- **Uncertainty comparison - sunburst diagram**  
  Sunburst diagrams showing relative contribution of individual processes & the level of certainty of each process' impacts.

### Global component selector
- Select a specific component with the global selector (shown below) to set all of the remaining tabs to show the design variant(s) modelled for the selected component. Within each of the tabs it is still possible to select another component using the local override selector.
