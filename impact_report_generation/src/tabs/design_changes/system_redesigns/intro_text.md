## Design Change Comparison

Compare the baseline design against one or more alternatives. This tab helps you visualize the impact of each proposed change.

### Graph Descriptions

- **Baseline vs Variant Bars**  
  Side-by-side bars of total single‐score for the baseline and each design variant.  
- **Delta Waterfall Chart**  
  Waterfall plot showing how individual component changes add up to the total difference.  
- **Radar (Spider) Chart**  
  Multi-axis plot comparing baseline and variants across multiple impact categories.  
- **Percent Change Bar Chart**  
  Bars showing % reduction or increase for each variant relative to the baseline.
